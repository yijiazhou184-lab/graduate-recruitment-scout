# Security and privacy

This project processes public job metadata and optional local preference profiles. It should not store credentials, application-account data, identification numbers, contact details, full resumes, or other unnecessary personal information.

Report a vulnerability privately to the repository maintainer before publishing exploit details. Include the affected version, reproduction steps using synthetic data, and the expected impact.

The Skill does not authorize login, CAPTCHA bypass, application submission, or collection from access-controlled pages. Generated workspaces and real profiles should remain untracked.
